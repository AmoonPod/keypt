# Changelog

All notable changes to Keypt are documented here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and releases use
[Semantic Versioning](https://semver.org/).

## [Unreleased]

### Added

- Local encrypted clipboard history for text, links, code, colors, and images.
- Search, keyboard navigation, pinning, retention controls, and configurable paste behavior.
- Password-manager exclusions, private clipboard markers, capture pause, and secure local storage.
- Sandboxed Electron boundary with validated IPC, strict CSP, ASAR integrity, and hardened fuses.
- Signed GitHub Releases with in-app update checks, explicit download, and restart-to-install.
- Unit, renderer, Electron E2E, packaged-app, CI, CodeQL, and dependency review coverage.
- macOS x64/ARM64 and Windows x64 packaging with checksums, SBOMs, and provenance attestations.
