# Support

Keypt is a community-maintained open-source project. Before opening an issue, search existing issues
and review the troubleshooting and privacy notes in the README.

- Use the bug report form with synthetic clipboard data only.
- Use the feature form for focused proposals that preserve Keypt's local, minimal scope.
- Report vulnerabilities privately through GitHub's security advisory flow as described in
  [SECURITY.md](SECURITY.md).

Public issues are not a private support channel and response times are not guaranteed. Never attach
real clipboard contents, vault files, credentials, signing material, or personal paths.
